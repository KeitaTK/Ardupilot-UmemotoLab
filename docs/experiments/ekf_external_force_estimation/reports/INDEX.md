## Phase 5: 革新的な観測値ゼロ強制案の導入（2026-04-15）
16. [2026-04-15_09:30_観測値ゼロ強制案の導入戦略.md](./2026-04-15_09:30_観測値ゼロ強制案の導入戦略.md)
    - 低振幅（デッドバンド）領域で観測値を0に固定する提案を検証。
    - シミュレーション結果: RMSE 38.3% 改善（0.0853 → 0.0526）、オーバーシュート 6.58倍 → 2.12倍へ削減。
    - 実装: 1行のコード追加（`z = 0.0f`）で、複雑な3対策（R×1000拡大、K制約、NaN検出）を統合。
    - 物理根拠: デッドバンド内で信号対雑音比が1以下となるため、観測値0という「アンカー」が有効。
    - 次ステップ: 実装 → リプレイ検証 → 詳細レポート作成。
