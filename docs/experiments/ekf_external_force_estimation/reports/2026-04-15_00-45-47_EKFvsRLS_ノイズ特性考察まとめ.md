# 2026-04-15 EKF vs RLS ノイズ特性 考察まとめ

**作成日時（JST）: 2026-04-15 00:40:02**

## 対象
- 元レポート: `2026-04-14_20:30_X軸推定値_平滑化パラメータ比較.md`
- 観測対象: PRX に現れる突発的ノイズ（特に 00000443 base）

## 問題意識
- base 設定では、正弦波成分に重畳する突発ステップが存在する。
- 平滑化（`Q_D`,`Q_DD`,`Q_C` 低下 + `R_MEAS` 上昇）で軽減できるが、完全抑制には限界がある。
- RLS 実験のほうが見かけ上より正弦波に近い結果だったため、アルゴリズム差による本質要因を整理する。

## 主要な整理結果

### 1. 「RLSのほうが本質的に低ノイズ」とは限らない
- 一般には、RLSが常にEKFより低ノイズという原理はない。
- ただし、単一周波数正弦 + バイアスのような低自由度モデルに強く拘束すると、RLSは見かけ上スパイクが出にくい。

### 2. EKFでスパイクが出る主因
- 観測外れ値時にも通常観測更新が通ると、`K * innovation` がそのまま状態に反映される。
- `R` を増やしても、単発外れ値に対しては「更新拒否」がない限り完全には抑え切れない。

### 3. パラメータの効き方（PRXスパイク観点）
- 最優先: `R_MEAS` 上昇（観測更新ゲイン低下）
- 次点: `Q_DD` 低下（速い変化の抑制）
- 次点: `Q_D` 低下（振幅急変の抑制）
- 補助: `Q_C` 低下（オフセット揺れ抑制）
- `Q_W` は主に周波数追従側で、PRXスパイク抑制の主ノブではない

### 4. 技術方針
- 方針1（優先）: ロバスト観測更新（innovation clipping + NIS閾値で外れ値更新拒否）
- 方針2: 上記に加え、`Q_D`,`Q_DD`,`Q_C`,`R_MEAS` の平滑化チューニング
- 方針3: 必要なら適応的R（innovation分散連動）へ拡張
