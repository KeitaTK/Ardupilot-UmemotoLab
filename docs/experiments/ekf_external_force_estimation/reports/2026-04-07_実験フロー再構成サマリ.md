# 実験フロー再構成サマリ (2026-04-07)

## 1. この文書の位置づけ
本レポートは、EKF外力推定実験群の重複内容を整理し、
時系列での意思決定フローを一貫して追えるように再構成した総括文書である。

## 2. 背景課題
- SW ONタイミングで周波数推定が不連続ジャンプする。
- 軸ごとの周波数成分差により、融合推定が高めに引っ張られる。
- 単一成分EKFで多成分入力を扱う際にギザつきが増える。

## 3. 検証フロー（要約）
1. 事象再現と原因切り分け
   - SW連動ジャンプはリセット起因であることを確認。
2. ノイズ・ゲート影響の検証
   - ゲート単独では改善は限定的、運用条件依存が大きい。
3. モデル仮説拡張
   - 二成分モデルで構造的ギザつきの説明力が向上。
4. 実運用向け比較
   - 固定周波数（0.45Hz）系が安定性指標で優位。
5. 最終統合
   - RMS/band-proxyベースのエネルギーゲートでX/Y選択を明確化。

## 4. 結論（現時点）
- 00000443/00000444では、X軸が有効でY軸は閾値未満になりやすい。
- 目標0.45Hzに対し、固定周波数寄り設定（または極小q_w）が最も再現性高く安定。
- 3軸無条件融合は本データセットでは優位性が低い。

## 5. 採用方針
- 推定軸選択: エネルギーゲートにより有効軸のみ採用。
- 周波数更新: 固定周波数寄り運用（低q_w）を基本にする。
- 評価軸: mae_hz、p95_step_hz、時系列ジャンプ有無を必須指標に維持。
