## 3. 二成分プロトタイプモデル
各軸について、ペイロード外力を次式でモデル化する。

y(t) = A1*sin(2*pi*f1*t + p1) + A2*sin(2*pi*f2*t + p2) + c

軸ごとの手順:
1. スライディングウィンドウのスペクトル解析で2つのピークを抽出する。
2. 2つの周波数を周期で並べ替える。
   - 長周期成分: 低周波
   - 短周期成分: 高周波
3. 最小二乗フィットで両成分の振幅を推定する。
4. 時系列補間により、各軸のサンプルごとの推定値を得る。

## 4. 長周期採用アルゴリズム
融合後の長周期候補として、以下の3手法を比較した。
- dual_long_raw
- dual_long_ewma
- dual_long_reliability_hold

両ログを通した総合最良:
- dual_long_ewma
- 参照: analysis/replay/results/diagnostics/dual_component_frequency_2026-04-04/summary.json

## 5. 現行出力がギザつく理由
主な要因は以下のとおり。
1. モデル不一致: 挙動に少なくとも2つの周波数成分が含まれる場合、単一周波数モデルでは表現力が不足する。
2. 軸間の不均質性: X/Y/Zで支配的成分が異なるため、融合時に上下の切り替わりが発生しやすい。
3. スイッチング挙動: ゲーティングやモード遷移により区分的な更新が入り、折れ点として現れる。

要するに、ギザつきはパラメータ調整ノイズだけではない。多成分信号を単一成分状態モデルに押し込めることで生じる、構造的な問題でもある。

## 8. EKFがRLSより滑らかでないのは妥当か？
はい、一般的には妥当である。
- RLS型の出力は、固定モデル仮定下で強いパラメータ平均化として働くため、見た目が滑らかになりやすい。
- EKFはイノベーションとモデル不一致に応答する状態推定器であり、実信号に混合成分が含まれる場合、モデル次数を上げるか出力平滑化を加えない限り、状態更新が目に見えて動くことがある。
- したがって、単一成分状態では多成分励起下で非平滑な挙動が生じることは想定内である。

## 9. 本プロトタイプでの推奨採用
時間平滑化を併用した長周期成分採用を用いる。
- 採用手法: dual_long_ewma
- 軸別の二周波数推定は維持しつつ、融合した長周期成分を主推定値として公開する。
