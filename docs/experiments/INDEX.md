# 実験レポートポータル

このディレクトリは、リポジトリ内の実験レポート正本を集約するための入口です。

## キャンペーン一覧
- [EKF外力推定](./ekf_external_force_estimation/README.md)

## 運用ルール
- レポート正本は `docs/experiments/<campaign>/reports/` に置く。
- ファイル名は `YYYY-MM-DD_日本語表題.md`（スペース無し・記号最小）に統一する。
- レポートには使用Programの相対パスを記載する。
- 未使用生成物は削除せず `docs/experiments/archive/YYYY-MM-DD/` に退避する。
